# Blockwild

Blockwild is an original voxel survival sandbox built with **Godot 4.4.1** and GDScript.

The project follows a milestone-driven roadmap from `0.0.1` through `1.0.3`. Each milestone is backed by meaningful source commits. Release automation publishes **source code only**; executable builds are intentionally not attached to GitHub Releases.

## Design pillars

- Freedom to explore, build, survive, and cooperate.
- Procedural discovery with memorable terrain, caves, ruins, and events.
- Fast, predictable voxel construction.
- Survival pressure without constant micromanagement.
- Emergent stories from interacting world systems.

## Development rules

- Engine target: Godot 4.4.1 stable.
- Main gameplay language: GDScript.
- No copied Minecraft assets, code, names, UI, sounds, or proprietary content.
- Quality is preferred over shortcuts when the choice materially affects maintainability or player experience.
- `main` should remain releasable; experiments belong on branches and are merged through pull requests where useful.
- Source-only releases: no EXE/AppImage/APK/DMG artifacts are uploaded to Releases.
